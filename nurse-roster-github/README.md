# ตารางเวรพยาบาล (Nurse Shift Roster)

เว็บสำหรับจัดตารางเวรพยาบาลอัตโนมัติ ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## ความสามารถ

- กำหนดจำนวนคนต่อเวร (เช้า / บ่าย / ดึก) แยกเวรธรรมดาและเวร refer แยกวันธรรมดาและวันหยุด
- วันหยุดเสาร์-อาทิตย์และวันหยุดราชการวันที่ตายตัวตั้งไว้ให้ แตะเพื่อเพิ่มวันหยุดอื่นได้
- กำหนดจำนวนพยาบาล และเลือกคนที่ขึ้นเวรในแต่ละเดือน
- บันทึกวันขอหยุด ทั้งวันหรือเฉพาะเวร และปุ่ม "ไม่อยู่เช้าวันธรรมดา" / "ไม่อยู่ดึกวันธรรมดา" ขอหยุดเวรนั้นทุกวันธรรมดาของเดือนในครั้งเดียว
- เงื่อนไข: ห้ามอยู่เวรติดกันเกิน N วัน (เลือกนับเวรธรรมดา / refer), เวรสูงสุดต่อวัน, ควบเวรไม่เกิน 16 ชม., เวรสูงสุดรายคน
- คน fix เช้า ER: ลงเวรเช้าวันทำการอย่างน้อยตามจำนวนวันที่ระบุ ไม่นับรวมตอนเฉลี่ย และยังได้รับ OT (บ่าย ดึก วันหยุด) เท่ากับคนอื่น
- กระจาย OT ให้เท่ากันทั้งจำนวนรวม เช้า/บ่าย/ดึก วันหยุด และเวร refer
- แก้ไขตารางเองได้ ระบบตรวจและแจ้งช่องที่ผิดเงื่อนไข พร้อมบอกเหตุผลของเวรที่ยังว่าง
- ส่งออก Excel (.xlsx) และ PDF, คัดลอกไปวางใน Excel
- สำรอง / นำเข้าข้อมูลเป็นไฟล์ .json

## เปิดใช้บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (Public)
2. อัปโหลด `index.html`, `style.css`, `app.js`, `README.md` ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก Source = **Deploy from a branch**, Branch = **main**, โฟลเดอร์ **/ (root)** แล้วกด Save
5. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

เปิดใช้ในเครื่องได้ด้วย โดยดับเบิลคลิก `index.html` (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และไลบรารี Excel/PDF)

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งาน ไม่ถูกส่งออกไปที่ใด

- แต่ละเครื่อง / แต่ละเบราว์เซอร์มีข้อมูลแยกกัน
- ล้างประวัติเบราว์เซอร์แล้วข้อมูลจะหาย ควรกด **ดาวน์โหลดไฟล์สำรอง** ในแท็บตั้งค่าเป็นระยะ
